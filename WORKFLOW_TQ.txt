PHẦN 3: CÁCH TẠO CÂU HỎI (YÊU CẦU CHÍNH XÁC)
========================================================================

LOẠI CÂU HỎI: Điền vào chỗ trống (填空题) — trắc nghiệm 4 đáp án

NGUỒN LẤY CÂU:
  1. Từ bài đọc chính (新闻速递 / 快速阅读 / 延伸阅读):
     → Lấy câu thật từ bài, xóa 1 từ/cụm từ quan trọng → điền vào chỗ trống
     → Ví dụ: "政党，是各国内政外交________的力量。"
     → Options: A.举足轻重  B.微不足道  C.可有可无  D.独当一面

  2. Từ phần 注释 (Chú thích):
     → Lấy câu định nghĩa trong chú thích, xóa từ khóa
     → Ví dụ: "'金砖国家'一词，________年由吉姆·奥尼尔首次提出。"
     → Options: A.1999  B.2001  C.2005  D.2008

FORMAT CÂU HỎI BẮT BUỘC:
  - Bắt đầu bằng tag nguồn: 【新闻速递】 hoặc 【快速阅读】
    hoặc 【延伸阅读】 hoặc 【注释】
  - Dòng 2: "原文填空：" (cho bài đọc) hoặc "注释填空：" (cho chú thích)
  - Dòng 3: Câu thật từ bài, chỗ trống là ________
  - 4 đáp án A/B/C/D song ngữ Trung–Việt (phiên âm latin nếu không có dấu)

PHÂN BỐ CÂU HỎI MỖI ĐƠN VỊ (mục tiêu ~15–18 câu):
  - 新闻速递: 6–7 câu
  - 注释 của 新闻速递: 2–3 câu
  - 快速阅读: 4–5 câu
  - 注释 của 快速阅读: 1–2 câu
  - 延伸阅读: 3–4 câu

PHẦN 4: ĐỊNH DẠNG FILE JSON
========================================================================

{
  "section": "第X单元 主题名 / Don vi X: Ten chu de",
  "questions": [
    {
      "question": "【新闻速递】原文填空：\n句子内容________句子继续。",
      "options": [
        "A. 选项A / tieng Viet",
        "B. 选项B / tieng Viet",
        "C. 选项C / tieng Viet",
        "D. 选项D / tieng Viet"
      ],
      "answer": "A. 选项A / tieng Viet"
    }
  ]
}

QUY TẮC QUAN TRỌNG:
  - KHÔNG dùng dấu " (ASCII double quote) bên trong chuỗi JSON
    → Thay bằng dấu ' (single quote) hoặc 《》 hoặc bỏ dấu
    → Ví dụ SAI:  "question": "奥尼尔说："金砖国家...""
    → Ví dụ ĐÚNG: "question": "奥尼尔说:'金砖国家...'"
  - Luôn dùng json.dump() với ensure_ascii=False để giữ ký tự Hán
  - Luôn verify bằng json.load() sau khi tạo file

CÁCH AN TOÀN NHẤT — Tạo file bằng Python script:
  1. Viết data vào biến Python (dùng nháy đơn ' cho chuỗi)
  2. Dùng json.dump() để ghi file
  3. Verify lại bằng json.load()
  Tuyệt đối KHÔNG dùng Write tool trực tiếp với nội dung JSON phức tạp
