3.1 — FILE BỘ ĐỀ THÔNG THƯỜNG (file1_fixed.json, file2.json, ...)
──────────────────────────────────────────────────────────────────
{
  "section": "tên bộ đề",
  "questions": [
    {
      "question": "Nội dung câu hỏi đầy đủ?",
      "options": [
        "A. Lựa chọn A",
        "B. Lựa chọn B",
        "C. Lựa chọn C",
        "D. Lựa chọn D"
      ],
      "answer": "B. Lựa chọn B"
    },
    ...
  ]
}

QUY TẮC BẮT BUỘC:
  - "answer" PHẢI là chuỗi đầy đủ khớp y hệt 1 phần tử trong "options"
  - "answer" KHÔNG được để rỗng ""
  - "options" bắt đầu bằng "A. " "B. " "C. " "D. " (chấm + khoảng trắng)
  - Có thể có 2, 3, hoặc 4 options (không bắt buộc đủ 4)

3.2 — FILE THEO CHƯƠNG (chuong1.json, chuong2.json, ...)
──────────────────────────────────────────────────────────
Cấu trúc y hệt bộ đề thông thường, THÊM field "chuong" ở mỗi câu:

{
  "section": "Chương 1",
  "questions": [
    {
      "question": "...",
      "options": [...],
      "answer": "...",
      "chuong": 1        ← BẮT BUỘC cho file chuong*.json
    },
    ...
  ]
}

Hoặc không có field "chuong" trong JSON, app sẽ tự gán khi load
(dùng hàm load_chuong_data()).

TÊN FILE CHUẨN:
  chuong1.json, chuong2.json, chuong3.json, ...
  bosungc1.json, bosungc2.json, ... (câu bổ sung chương 1, 2, ...)

3.3 — FILE .TXT (định dạng đơn giản)
──────────────────────────────────────
App cũng đọc file .txt với định dạng:

PHẦN 4: CÁCH APP HOẠT ĐỘNG (quiz_app.py)
========================================================================

4.1 — MÀN HÌNH CHÀO (show_welcome)
────────────────────────────────────
1. Quét tất cả subfolder trong TN_MMT\ → tìm folder có file .json/.txt/.pdf
2. Dropdown "Môn học" để chuyển môn
3. Nếu môn có chuong*.json:
   → Hiển thị "Ôn theo chương" (cards với icon + dropdown phạm vi câu)
   → Dropdown phạm vi: Tất cả / Câu 1-50 / Câu 51-100 / ...
4. Phần "Ôn theo bộ đề" (radio buttons):
   → Khi chọn 1 bộ đề có >50 câu → hiện thêm chips chọn phạm vi
   → Chips: "Tất cả (N câu)" / "Câu 1–50" / "Câu 51–100" / ...
5. Checkbox "Xáo trộn câu hỏi"
6. Nút "BẮT ĐẦU ÔN TẬP"

4.2 — MÀN HÌNH CÂU HỎI (show_quiz)
────────────────────────────────────
- Hiển thị từng câu, chọn đáp án → màu xanh/đỏ
- Nút "Câu tiếp" / "Câu trước" / "Bỏ qua"
- Badge hiển thị tên chương hoặc tên bộ đề
- Nút "Quay về" trang chủ

4.3 — MÀN HÌNH KẾT QUẢ (show_result)
───────────────────────────────────────
- Điểm, phần trăm, nhận xét (Xuất sắc / Khá / Cần ôn thêm)
- "Làm lại câu sai" — chỉ ôn lại câu trả lời sai
- "Thi lại" — làm lại từ đầu cùng bộ câu
- "Về trang chủ"

4.4 — LOGIC CHỌN CÂU
──────────────────────
start_quiz(mode, num, batch="all"):
  - mode="all" → toàn bộ questions_db
  - mode=<section_key> → lọc theo section
  - batch="0" → lấy câu [0:50]
  - batch="50" → lấy câu [50:100]
  - batch="all" → lấy tất cả

start_quiz_clo(selections):
  - selections = [(ch_num, batch_val), ...]
  - Gộp câu từ nhiều chương, lọc theo batch

PHẦN 11: LƯU Ý KỸ THUẬT QUAN TRỌNG
========================================================================

1. ENCODING:
   - Luôn dùng encoding='utf-8' khi đọc/ghi file JSON, txt
   - Khi in ra terminal Windows: dùng PYTHONIOENCODING=utf-8 hoặc
     sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

2. FLET VERSION:
   - App dùng Flet >= 0.80 (có nhiều API đổi tên)
   - Đã có patch tương thích: ft.colors = ft.Colors, ft.icons = ft.Icons
   - Có thể có DeprecationWarning — bỏ qua, app vẫn chạy được

3. ANSWER PHẢI KHỚP OPTION:
   - answer = "B. Văn Cao"  phải khớp y hệt với options có "B. Văn Cao"
   - Dấu ngoặc kép trong JSON có thể là " " (curly quotes) hoặc " " (straight)
   - Nếu mismatch → script fill sẽ báo CẢNH BÁO và không ghi vào JSON

4. CẤU TRÚC OPTIONS:
   - Prefix: "A. " "B. " "C. " "D. " (chữ hoa, chấm, khoảng trắng)
   - KHÔNG dùng "A) " hay "A: "
   - Cần khớp chính xác để app hiển thị đúng màu khi chọn

5. TESSERACT OCR:
   - tesseract.exe: C:\Program Files\Tesseract-OCR\tesseract.exe
   - TESSDATA_PREFIX = c:\vscode\code\TN_MMT  (chứa vie.traineddata)
   - KHÔNG đổi TESSDATA_PREFIX sang thư mục khác

6. VS CODE:
   - Sau khi script ghi JSON xong → chuột phải file JSON → "Revert File"
   - ĐỪNG để file JSON có thay đổi chưa lưu khi chạy script ghi
